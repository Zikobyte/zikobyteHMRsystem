✓ Best Practices Included

  • RAID 1 mirroring on primary — zero downtime on disk failure
  • RAID 5 on backup — space-efficient with single-disk tolerance
  • Daily incremental + weekly full backup schedule
  • AES-256 encryption for all patient records (HIPAA-aligned)
  • Separate tablespaces: audit logs vs clinical data
  • 5-year retention policy with automated archiving

→ Growth Considerations

  • Digital radiology (DICOM): adds 2–5 TB/year if implemented
  • Telemedicine recordings: ~500 MB per recorded session
  • Patient portal attachments: ~50 MB per active patient
  • Report exports (Excel/PDF): ~5 GB/year accumulation
  • Re-evaluate storage annually at 70% capacity threshold
  • Consider SAN/NAS expansion for scalability beyond 5 years

7. Important Notes

This report does not include storage for medical imaging (DICOM/PACS) — digital X-rays, CT scans, MRIs, and ultrasound images — as ZMC currently uses paper-based or separate imaging systems. If digital imaging is integrated into the EHR in the future, storage requirements could increase by 2–10 TB per year depending on imaging volume. A separate DICOM storage server (PACS server) should be planned for at that stage.

All figures are conservative estimates based on ZMC's current operational scope. Actual consumption will vary based on patient volumes, data entry verbosity, and module usage patterns.
